# DeskPet 猫娘精灵 · Nano Banana 2 单帧生成指南（修订版）

> 适用模型：Google Gemini `gemini-3.1-flash-image-preview`（香蕉 2）
> 参考模型：`gemini-3-pro-image-preview`（香蕉 Pro，效果更佳）
> 修订日期：2026-04-29
>
> ⚠️ **本版本与上一版的重要区别：**
> - Gemini 单次只能生成一张图，每帧需独立生成
> - 提示词已全部改为"单帧单图"模式
> - 所有模糊量词（轻微、约2度）已替换为大幅度、易辨认的动作描述

---

## 一、通用规格（每帧必须遵守）

| 参数 | 值 |
|---|---|
| 单帧分辨率 | 64×64 px |
| 画布分辨率 | 512×512 px（8×8 像素格，8px/格） |
| 背景 | 透明 PNG |
| 色彩 | 16~32 色调色板 |
| 风格 | 像素画，锐利边缘，无抗锯齿，无羽化 |
| 输出 | 每帧单独 PNG → 后处理 → Aseprite 拼合 |

---

## 二、通用前缀（每条提示词都需附加）

```
像素画风格，64×64 像素，PNG 透明背景，16~32 色调色板，
边缘锐利，无抗锯齿，无羽化，居中对齐，无描边，无签名，无水印。
```

---

## 三、逐帧提示词（单帧单图）

> 每个 prompt 生成一张 64×64 的独立 PNG 帧。
> 帧间无继承关系，每条提示词需完整描述该帧的全部内容。
