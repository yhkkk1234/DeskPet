## 一、总览

DeskPet 的宠物渲染采用**策略模式**，支持三种渲染器：

| 渲染器 | 状态 | 说明 |
|--------|------|------|
| **CSS** | ✅ 当前 | Emoji + CSS keyframes 占位 |
| **Spritesheet** | ✅ 框架就绪 | Aseprite PNG+JSON，你在这里 |
| **Spine** | 🔒 预留 | 未来升级 |

你现在要做的就是用 **Aseprite** 按照本规范制作 spritesheet，导出后直接替换即可。

## 二、动画状态定义

桌宠需要 **8 种动画状态**，每种对应 spritesheet 的一行：

| 行号 | 状态 ID | 名称 | 帧数 | FPS | 循环 | 描述 | 画面要点 |
|------|---------|------|------|-----|------|------|----------|
| 0 | `idle` | 待机/呼吸 | 4-8 | 4 | ✅循环 | 默认状态，轻微呼吸起伏 | 身体微微上下起伏，尾巴可能有微动 |
| 1 | `happy` | 开心 | 4-6 | 6 | ✅循环 | 爱恨值 > 50 时的表现 | 蹦跳、眼睛弯弯、可能有小星星/爱心 |
| 2 | `content` | 满足 | 4-6 | 4 | ✅循环 | 爱恨值 20-50 时的表现 | 温和摇摆、微微微笑、放松姿态 |
| 3 | `curious` | 好奇 | 4-6 | 5 | ✅循环 | 好奇心触发时的表现 | 歪头、前身前探、眼睛睁大 |
| 4 | `cold` | 冷淡 | 3-4 | 3 | ✅循环 | 爱恨值 -50 到 -20 | 转身/扭头、微微颤抖 |
| 5 | `distant` | 疏远 | 2-3 | 2 | ✅循环 | 爱恨值 < -50 | 闭眼/背对、几乎不动 |
| 6 | `speaking` | 说话 | 3-5 | 6 | ✅循环 | 正在回复对话时 | 嘴巴开合、身体略微前倾 |
| 7 | `surprise` | 惊喜 | 4-6 | 8 | ❌一次 | 截图识别完成/特殊反馈 | 弹跳+放大+回弹，一次性播放 |

### 每种状态的帧数建议

```
idle:     [静止] [微微上升] [顶点] [微微下降] → 循环
happy:    [弹起] [最高点] [落下] [着地] [微弹] → 循环
content:  [静止] [微左倾] [静止] [微右倾] → 循环
curious:  [正视] [右歪头] [正视] [左歪头] → 循环
cold:     [正视] [转右] [稍背对] → 循环
distant:  [闭眼下] [闭眼静止] → 循环（慢）
speaking: [闭嘴] [半张] [大张] [半张] → 循环
surprise: [正常] [弹起] [最高点] [落下] [轻微回弹] [静止] → 一次
```

## 三、画布规格

### 推荐规格

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **单帧尺寸** | 48 × 48 px | 像素风可用 32×32 |
| **缩放倍数** | 2× | 渲染时放大2倍显示（96×96 屏幕像素） |
| **总列数** | 8 列 | 每行最多8帧 |
| **总行数** | 8 行 | 对应8种动画状态 |
| **总画布** | 384 × 384 px (48×8列 × 48×8行) | 像素风：256 × 256 px (32×8 × 32×8) |
| **背景** | 透明 | PNG with alpha |
| **调色板** | 无限制 | 但桌宠通常扁平色彩为主 |

### Spritesheet 布局

```
     Col 0    Col 1    Col 2    Col 3    Col 4    Col 5    Col 6    Col 7
Row 0 [idle_____] [idle_____] [idle_____] [idle_____] [idle_____] ...    ← idle (4-8帧)
Row 1 [happy____] [happy____] [happy____] [happy____] ...                 ← happy
Row 2 [content__] [content__] [content__] [content__] ...                 ← content
Row 3 [curious__] [curious__] [curious__] [curious__] ...               ← curious
Row 4 [cold_____] [cold_____] [cold_____] ...                             ← cold
Row 5 [distant__] [distant__] ...                                        ← distant
Row 6 [speaking_] [speaking_] [speaking_] [speaking_] ...                ← speaking
Row 7 [surprise_] [surprise_] [surprise_] [surprise_] [surprise_] ...  ← surprise (一次性)
```

**不满8帧的行**：后面的帧留空即可，框架会根据配置的列数计算，不影响。

## 四、Aseprite 导出设置

### Step 1: 制作动画

1. 新建 Aseprite 文件，画布 48×48（或 32×32 像素风）
2. 按行组织帧：第1行 = idle，第2行 = happy，以此类推
3. 每种动画在 Timeline 中作为一个 Tag（方便管理）

### Step 2: 导出 Sprite Sheet

1. **File → Export Sprite Sheet**
2. 设置：
   - **Sheet Type**: Horizontal Strip（每状态一行）
   - **Constraints**: Fixed Rows = 8
   - **Border Padding**: 0, **Inner Padding**: 0
   - ✅ 勾选 **Trim**（可选，但建议不勾以保持对齐）
3. **JSON Data**:
   - ✅ 勾选 **Export JSON**
   - 格式选 **Array (Hash)** — 含 `frameTags`
4. 输出文件名：
   - PNG: `pet_spritesheet.png`
   - JSON: `pet_spritesheet.json`

### Step 3: 放置文件

```
src/assets/pet/
├── pet_spritesheet.png
└── pet_spritesheet.json
```

### Step 4: 配置

在 DeskPet 面板的「渲染模式」中：
- 选择「精灵图」模式
- 填入路径和参数
- 或者开发者在代码中配置默认路径

## 五、JSON 格式参考

Aseprite 导出的 JSON 大概长这样：

```json
{
  "frames": [
    {
      "filename": "idle_0",
      "frame": { "x": 0, "y": 0, "w": 48, "h": 48 },
      "rotated": false,
      "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 48, "h": 48 },
      "sourceSize": { "w": 48, "h": 48 },
      "duration": 250
    },
    {
      "filename": "idle_1",
      "frame": { "x": 48, "y": 0, "w": 48, "h": 48 },
      ...
    }
  ],
  "meta": {
    "image": "pet_spritesheet.png",
    "size": { "w": 384, "h": 384 },
    "frameTags": [
      { "name": "idle", "from": 0, "to": 3 },
      { "name": "happy", "from": 8, "to": 12 },
      ...
    ]
  }
}
```

**PetRenderer 框架目前使用简单的行列定位**，不需要解析 Aseprite 的 JSON tag。但如果你希望未来更灵活，JSON 格式是预留好的。

## 六、像素风建议

如果你选择像素风（推荐入门）：

### 调色板建议

```
黑色轮廓:   #333333 或 #2D2D2D
主色:       根据桌宠设计选1-2色
高光:       主色 + 30% 明度
阴影:       主色 - 20% 明度
白色高光:   #FFFFFF（眼睛、鼻子）
```

### 32×32 的像素画技巧

- 每 "帧" 只需改关键像素（呼吸改 2-3 像素就够了）
- idle: 只让肚子/胸部上下移动1像素就很明显
- happy: 身体整体上移2-3像素 + 尾巴波动
- speaking: 只改嘴巴区域（3-5像素变化）
- distant: 把眼睛帧换成闭眼版

### 48×48 可以更精致

如果 32×32 感觉太粗糙，48×48 是个好平衡：
- 有足够空间画简单阴影
- 可以加小装饰（蝴蝶结、铃铛等）
- 表情更丰富（眉毛、瞳孔移动）

## 七、替换流程

素材制作完成后：

1. 导出 `pet_spritesheet.png` 和 `pet_spritesheet.json` 到 `src/assets/pet/`
2. 在 App.vue 中设置默认 spritesheet 配置：

```typescript
// 在 usePetRenderer 中配置默认路径
setSpriteConfig({
  src: '/src/assets/pet/pet_spritesheet.png',
  jsonSrc: '/src/assets/pet/pet_spritesheet.json',
  frameWidth: 48,
  frameHeight: 48,
  scale: 2,
  rows: 8,
  cols: 8,
})
setRenderer('spritesheet')
```

3. 或在面板中手动切换渲染模式为「精灵图」，填入路径

**零代码改动**：如果帧数/尺寸改变，只需调整 `spriteConfig` 中的参数。

## 八、测试检查清单

素材放入后，检查以下项目：

- [ ] idle: 呼吸动画是否循环流畅
- [ ] happy: 弹跳是否自然，不要过快
- [ ] content: 微动是否温和，不要突兀
- [ ] curious: 歪头方向是否交替自然
- [ ] cold: 转身是否平滑
- [ ] distant: 近乎静止，2fps 够慢
- [ ] speaking: 嘴巴开合速度适中
- [ ] surprise: 一次性弹跳播放后是否回到 idle
- [ ] **状态切换 crossfade**：从 happy 切到 cold 是否平滑（200ms 淡入淡出）
- [ ] **情感联动**：好感度从 >50 切到 <-50 后，表情是否从 😊 变为 😤 再到动画从 happy 变 distant

## 九、快速开始模板

如果你想在 Aseprite 中快速开始：

1. 新建文件：48×48 像素，8帧，8个 Tag
2. 第1帧画最基本的猫/精灵形状
3. 复制帧，每帧只改需要动的部分
4. File → Export Sprite Sheet
5. 放入项目，切换渲染模式

**最小可测试集**：只要 `idle`（Row 0）的 4 帧做好，就能在框架中看到效果！其他行暂时留空或复制 idle 即可。
