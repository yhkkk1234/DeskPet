# DeskPet 桌宠

**一个把「灵魂」存成本地文件的 AI 桌面宠物。**

它会在你的桌面上生活：记住你们聊过的事，会开心也会生气，会对你的作品发表看法，一小时不理它就睡着、醒来跟你讲梦见了什么。

而它的「灵魂」——人格、记忆、对你的印象——是一个**加密文件，在你自己硬盘上**（`%APPDATA%/DeskPet/`），不属于某家公司的数据库。你可以备份它、带着它换机器、或送它去做一次「灵魂传送」：签名消逝、再重生，人格被轻微扰动，原体记忆变得模糊。

> **状态**：v0.1.0 早期体验版 · 仅 Windows 10/11 · MIT 开源 · [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 它和别的桌宠有什么不同

桌宠 / AI 陪伴这个品类不缺功能，缺的是**归属感**和**连续性**。DeskPet 在三点上做了不同的选择：

| | 常见做法 | DeskPet 的选择 |
|---|---|---|
| **数据归属** | 记忆存在供应商的云账号里，换 App 就归零 | 灵魂是本地加密文件，你拥有、可备份、可迁移 |
| **信任模型** | 用官方额度、按订阅付费、数据经中转 | **自带 API Key**，直连你选的服务商（或本地 Ollama）；无遥测、无中转、无自动更新 SDK |
| **灵魂的唯一性** | 「复制一份」是零成本的 | 「灵魂传送」是**有损**的：人格微扰 + 记忆模糊，复制不出第二个它 |
| **技术选型** | Electron（常驻 100 MB+ 的 Chromium） | Rust + Tauri，常驻体积与内存都低一个量级 |

一句话：**它更像个「你的」宠物，而不是「租来的」宠物。**

![DeskPet 演示：待机时头部会跟随鼠标转动](docs/demo-idle.gif)

*↑ 它会在桌面上待机眨眼，并且**头部始终看向你的鼠标**（9 宫格头部素材 + 挖洞叠层实现）。*

## 🚀 快速开始

### 1. 下载安装

从 [Releases](../../releases) 下载最新的 Windows 安装包，双击安装即可：

- **`DeskPet_0.1.0_x64-setup.exe`**（NSIS，推荐）— 体积更小，安装更快
- **`DeskPet_0.1.0_x64_en-US.msi`**（WiX）— 适合企业环境批量部署

> 首次启动会随机生成一只桌宠，它会出现在桌面左上角。

> ⚠️ **安装包未做代码签名**，Windows SmartScreen 可能提示「未知发布者」。这是个人开源项目的常见情况，源码可自行审计；在意的话请从源码构建。

<details>
<summary>还没发布安装包？从源码运行 / 自行打包</summary>

```bash
cd DeskPet
npm install
npx tauri dev      # 开发模式
npx tauri build    # 打包成 msi / exe
```

需要 Node.js、Rust 工具链与 [Tauri 的系统依赖](https://tauri.app/start/prerequisites/)。
</details>

### 2. 配置 AI 接口（**必须，否则桌宠不会说话**）

DeskPet 本身不带 AI，需要你提供一个**兼容 OpenAI 协议**的 API Key。推荐用 DeepSeek（便宜、中文好）：

1. 注册 [DeepSeek](https://platform.deepseek.com/) 并创建 API Key
2. 双击桌宠 → 点 **⚙️**（或按 `Ctrl+Alt+S`）打开设置
3. 在「AI 配置」填写：
   - **Endpoint**：`https://api.deepseek.com/v1`（已预填）
   - **API Key**：你的 `sk-...` 密钥
   - **Model**：`deepseek-chat`（已预填）
4. 点「保存」

> 首次启动如果没配置，会自动弹出设置窗口引导你。
>
> **也支持其它 OpenAI 兼容服务**：OpenAI、智谱 GLM、通义千问、Moonshot、本地 Ollama 等，只要改 Endpoint / Model / Key 即可。

> **语音输入（可选）**：DeepSeek 不支持语音转写，需要另配支持 Whisper 的端点（如 OpenAI `/v1` 或 Groq）。在设置 → AI 配置 →「语音输入 STT」填写后，对话窗口的 🎤 按钮即可用。

### 3. 开始玩

| 操作 | 方式 |
|------|------|
| 对话 | 点击桌宠 / 按 `Ctrl+Alt+C` |
| 截图提问 | 按 `Ctrl+Alt+X` 框选区域 |
| 设置 | 按 `Ctrl+Alt+S` |
| 退出 | 托盘图标右键 → 退出 / 按 `Ctrl+Alt+Q` |
| 拖动 | 按住桌宠拖到任意位置 |

## 💰 关于费用

DeskPet 调用 AI 会消耗你自己的 API 额度。粗略参考（以 DeepSeek 为例，**价格仅供参考，请以供应商最新定价为准**）：

- 普通闲聊：约 ¥0.001~0.01 / 条
- 记忆压缩（每 20 条对话触发一次）：约 ¥0.01 / 次
- 文档摘要（导入时一次性）：约 ¥0.05~0.5 / 篇（取决于长度）

> 不聊天就不花钱。桌宠待机时只在后台跑动画和定时 tick，不调 AI。

## ⚠️ 已知限制

- **仅 Windows**：截图用了 Win32 API，暂不支持 macOS / Linux
- **需联网**：对话、情感、记忆、TTS 都依赖在线 AI；离线时桌宠会动但不会说话
- **Edge TTS 需联网**：离线自动降级到系统语音
- **生图需独立配置**：DeepSeek 不支持生图，需另配支持生图的 API（如 OpenAI DALL·E、其它生图服务）
- **语音输入需 Whisper 端点**：DeepSeek 不支持语音转写，需另配 OpenAI/Groq 等
- **记忆精度**：本地情感/实体识别是规则式的，复杂语境（反讽、否定句）可能误判；AI 层会兜底
- **长文档**：导入超 5 万字的文档会截取前 5 万字生成摘要，可能丢失后文细节

完整的技术细节见仓库内的 `技术设计文档_v2.md`，开发进度见 `进度总结.md`。

## 🔒 隐私说明

**一句话：DeskPet 没有自己的服务器，但它需要把你的一部分数据发给你自己配置的那个 AI 接口。**

- **本机存储**：对话、记忆、灵魂文件、日记、印象都存在 `%APPDATA%/DeskPet/` 下（SQLite + 加密存档）
- **API Key 加密存储**：AI / 天气 / 生图密钥经 AES-256-GCM 加密后落盘（`master.key` 派生），前端只显示掩码，**不会**进源码、不会随安装包分发、不会上传
- **日志不含密钥**：请求失败时的错误信息会先剥掉 URL 并把 `appid` 之类的凭据参数掩码后再写日志（`weather_service.rs::redact_api_key`）
- **会发送到你配置的 AI 接口的内容**（仅发往你自己填的 Endpoint，DeskPet 不中转、不额外上报）：
  - 对话文本、人格/印象/记忆摘要（对话与记忆压缩需要）
  - **截图**：截图识图与「增强好奇心」会把截图图像数据发给该接口做识别（**图像数据不写盘**，仅内存中处理）
  - 导入的文档正文（生成摘要时）
  - 语音输入时的录音转写（需另配支持 Whisper 的端点）
  - 开启「剪贴板感知」后，剪贴板内容的前 40 个字符
- **截图不留存**：截图识图后图像数据只在内存中处理，**不写盘**
- **剪贴板感知默认关闭**：开启后仅对链接/长文本触发搭话
- **增强好奇心需授权**：后台截屏分析首次开启前会弹出隐私确认

> 数据流向的完整清单、密钥存储方式与已知的安全权衡（含 `assetProtocol` scope 为何放行全部路径）见 [`SECURITY.md`](SECURITY.md)。

> 不想让任何数据离开本机？把 Endpoint 指向本地 Ollama 之类的离线服务即可，此时除 Edge TTS 语音外全链路不出网。

## 🛠️ 开发者信息

### 技术栈

Tauri 2 + Vue 3 + TypeScript（前端）/ Rust（后端）

### 本地运行

```bash
cd DeskPet
npm install

# 开发模式（热更新）
npm run tauri:dev

# 打包（产出 msi 与 nsis 安装包）
npm run tauri:build
```

需要 Node.js 20+、Rust 工具链，以及 [Tauri 的系统依赖](https://tauri.app/start/prerequisites/)。
Windows 上打包会用到 WiX 与 NSIS —— Tauri CLI 会在首次 `tauri:build` 时自动下载。

### 测试

```bash
cd DeskPet/src-tauri && cargo test --offline    # Rust 后端单元测试
cd DeskPet && npm run build                     # vue-tsc 类型检查 + 前端打包
```
