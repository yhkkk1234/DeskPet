# DeskPet 美术需求文档 — P19 动画状态机升级

> **版本**: v2.1
> **最后更新**: 2026-04-27（Sleep→LieDown分离 / 拖拽序列修正为surprise→dragged→pout三阶段）
> **给**: 美术
> **背景**: P19 重构后动画架构变更——情绪不再锁定循环动画，改为一次性情绪反应 + 日常行为池。需要新增多种动作帧。
> **前置**: 请先阅读《美工素材规范.md》了解基础导出流程

---

## 一、架构变更说明（美术需要知道什么）

**旧架构**：好感度高 → 宠物永远在"开心跳跃"循环 → 不自然

**新架构（P19）**：
- 基态永远是 **idle**（站立呼吸）
- 情绪反应 = **一次性动画**（播 1~2 秒后回 idle）
- 日常行为 = 随机触发的小动作（播完回 idle）
- 好感度只影响"日常做什么动作的概率"，不影响循环动画

**这意味着**：你需要画更多**一次性动作**（打哈欠、走路、被拎起来等），而不只是 8 种循环表情。

## 三、新增需求清单

### 3.1 日常行为动作（日常行为池，随机触发）

这些是宠物空闲时随机播放的小动作，每个播 0.5~3 秒后回 idle：

| # | 动作 ID | 名称 | 优先级 | 帧数建议 | 循环 | 时长 | 画面描述 | 触发场景 |
|---|---------|------|--------|---------|------|------|----------|----------|
| A1 | `Walk` | 踱步走路 | **P0** | 6-8 | ✅循环 | 持续 | 迈腿交替，身体微微左右摆动，尾巴自然晃动 | wander 行为触发时（好感高时更常出现） |
| A2 | `Yawn` | 打哈欠 | **P0** | 5-6 | ❌一次 | ~1.5s | 闭眼→张大嘴→闭嘴→睁眼→回idle | 随机日常行为 |
| A3 | `Stretch` | 伸懒腰 | P1 | 5-6 | ❌一次 | ~1.5s | 前肢前伸→弓背→回正 | 随机日常行为 |
| A4 | `Sleep` | 睡觉 | P1 | 4-6 | ✅循环 | 持续 | **已趴好**的姿态，闭眼，身体缓慢起伏呼吸（比idle更慢，~3fps），可能有小Z字。不含站立→趴下过渡（由 LieDown 负责） | snooze 行为触发时（好感低时常出现），播前先经 LieDown 过渡 |
| A5 | `LookAround` | 左右张望 | P2 | 4-6 | ❌一次 | ~1s | 先看左边→回正面→看右边→回正面 | 随机日常行为 |

**A1 Walk 是最高优先级**——当前宠物移动时没有任何迈腿效果，只是图片在平移，非常不自然。

### 3.1b 过渡动作

| # | 动作 ID | 名称 | 优先级 | 帧数建议 | 循环 | 时长 | 画面描述 | 触发场景 |
|---|---------|------|--------|---------|------|------|----------|----------|
| T1 | `LieDown` | 趴下过渡 | **P1** | 4-6 | ❌一次 | ~0.8s | 从站立姿态→蹲下→趴下，膝盖弯曲→身体前倾→落地 | snooze 行为触发时，先播 LieDown（一次性）→ 再切 Sleep（循环） |

| # | 动作 ID | 名称 | 优先级 | 帧数建议 | 循环 | 时长 | 画面描述 | 触发场景 |
|---|---------|------|--------|---------|------|------|----------|----------|
| B1 | `Dragged` | 被拎起来 | **P0** | 4-6 | ✅循环 | 持续 | 四肢悬空下垂，身体轻微挣扎/晃动，表情紧张或不满 | 拖拽宠物时 |

## 五、各动作逐帧参考

### A1 — Walk（踱步）⭐ 最高优先级

```
帧1: 右前左后（左脚着地右脚抬起）
帧2: 过渡（双脚接近地面）
帧3: 双脚着地（身体稍低）
帧4: 左前右后（右脚着地左脚抬起）
帧5: 过渡（双脚接近地面）
帧6: 双脚着地（身体稍低）
→ 循环
```

**要点**：
- 身体有轻微上下起伏（走路时重心变化）
- 尾巴随步伐自然摆动
- 头部保持朝前，不左右转
- 与 idle 的区别：有明显的腿部交替动作

### A2 — Yawn（打哈欠）

```
帧1: 正常idle姿态
帧2: 眼睛微闭
帧3: 嘴巴张开（中等）
帧4: 嘴巴大张（最大）+ 眼睛紧闭
帧5: 嘴巴合上 + 眼睛微睁
帧6: 回到idle
→ 结束
```

### A4 — Sleep（睡觉）

```
帧1: 已趴下，闭眼，呼吸谷底
帧2: 趴着呼吸上升
帧3: 趴着呼吸顶点
帧4: 趴着呼吸下降
→ 循环（比idle更慢，建议3fps）
```

**要点**：
- 第1帧即已趴好，**不含站立→趴下过渡**（过渡由 LieDown 单独负责）
- 身体姿态与 idle 完全不同（趴下 vs 站立）
- 可以在头顶/旁边画小 "Z" 字符号（帧3-4出现，帧1-2消失）
- 呼吸幅度比 idle 大一些，频率更慢

### T1 — LieDown（趴下过渡）

```
帧1: 正常idle站立姿态
帧2: 膝盖微弯，身体开始前倾
帧3: 蹲下，身体前倾幅度最大
帧4: 前肢触地
帧5: 完全趴下（衔接 Sleep 帧1的姿态）
→ 结束
```

**要点**：
- 这是一个约 0.8s 的一次性过渡动画，播完后立即切换到 Sleep 循环
- 最后一帧的姿态应与 Sleep 的第1帧**完全一致**（无缝衔接）
- 画面重点在膝盖弯曲→前倾→落地的流畅过程
- 由于 LieDown 和 Sleep 在精灵表中相邻排列（行13→行14），crossfade 过渡会很自然

### B1 — Dragged（被拎起来）⭐ 最高优先级

```
帧1: 身体整体上提，四肢下垂
帧2: 身体微左倾，腿微摆
帧3: 身体微右倾，腿微摆
帧4: 回到中间，四肢下垂
→ 循环
```

**要点**：
- 整体姿态像"被拎着脖子"——头部被拉长/抬高的感觉
- 四肢放松下垂，不用力
- 表情：不开心/紧张（眉毛微皱或嘴巴微张）
- 身体轻微左右摆动（被拎着晃的感觉）

### B2 — Pout（不高兴嘟嘴）⭐ 最高优先级

```
帧1: 刚落地（从Dragged下来的姿态）
帧2: 皱眉 + 嘟嘴
帧3: 扭头转向一边（背对用户方向）
帧4: 保持扭头
帧5: 转回来，表情恢复
帧6: 回到idle
→ 结束
```

**要点**：
- 这是从 Dragged 结束后的自然过渡
- 嘟嘴/皱眉是重点——让用户看到"我不高兴了"
- 扭头动作表示"不想理你"

// executeAction 中对 snooze 的特殊处理：
// snooze 执行时：playOneShot('lieDown', 800) → 然后 setAnimationState('sleep')

```typescript
// useAnimation.ts executeAction 中 snooze 分支
if (action === 'snooze') {
  const gen = ++animationGen
  isPerformingBehavior.value = true
  // 先播趴下过渡
  currentAnimationState.value = 'lieDown'
  setTimeout(() => {
    if (animationGen !== gen) return
    // 过渡结束，切到睡眠循环
    currentAnimationState.value = 'sleep'
  }, 800)
}
```

### Step 5: 拖拽交互 — 三阶段序列

拖拽采用 **surprise → dragged → pout** 三阶段序列，不修改 `playOneShot` 通用逻辑：

```
mousedown ─→ surprise(400ms) ─→ dragged(循环) ─→ 松手 ─→ pout(1.2s) ─→ idle
              "吓一跳！"         "被拎着晃"        drop     "哼！"
```

```typescript
// useAnimation.ts 新增 startDragSequence()
async function startDragSequence(onDragEnd: () => Promise<void>): Promise<void> {
  const gen = ++animationGen
  isPerformingBehavior.value = true
  stopDailyRoutine()

  // 阶段1: 惊吓 400ms
  currentAnimationState.value = 'surprise'
  await new Promise(r => setTimeout(r, 400))
  if (animationGen !== gen) return

  // 阶段2: 被拎（持续循环，直到松手）
  currentAnimationState.value = 'dragged'
  await onDragEnd() // OS startDragging 的 finally 回调
  if (animationGen !== gen) return

  // 阶段3: 放下后不高兴（松手后播 pout 后回 idle）
  currentAnimationState.value = 'pout'
  await new Promise(r => setTimeout(r, 1200))
  if (animationGen !== gen) return

  currentAnimationState.value = 'idle'
  isPerformingBehavior.value = false
  startDailyRoutine()
}
```

```typescript
// App.vue onPetMouseDown — 调用方
function onPetMouseDown(e: MouseEvent) {
  if (e.button !== 0) return
  petY.value = -14
  didDrag = false

  const win = getCurrentWindow()
  startDragSequence(() => new Promise<void>((resolve) => {
    win.startDragging().finally(() => {
      petY.value = 0
      Promise.all([beforePromise, win.outerPosition()]).then(([before, after]) => {
        if (Math.abs(after.x - before.x) > 3 || Math.abs(after.y - before.y) > 3) {
          didDrag = true
        }
      })
      resolve()
    })
  })).finally(() => {
    startDailyRoutine()
  })
}
```

> **关键设计**：`startDragSequence` 使用独立的 `animationGen` 控制，与 `playOneShot` 的 surprise 逻辑互不干扰。截图/teleport 触发的 `playOneShot('surprise', ...)` 仍然正常回 idle，不会串到 dragged。`animationGen` 代数保护确保日常行为在此期间不会覆盖动画状态。

## 九、验收标准

### P0 验收

- [ ] Walk 循环流畅，有明显的迈腿效果
- [ ] Dragged 循环有悬空挣扎感
- [ ] Pout 一次性播完后自然过渡到 idle
- [ ] 新旧动画之间切换 crossfade（200ms 淡入淡出）无跳变
- [ ] 新精灵表 JSON 中 frameTags 包含所有新增 Tag

### P1 验收

- [ ] Yawn 的嘴巴张合自然
- [ ] Stretch 有弓背前伸的舒展感
- [ ] LieDown 从站立→趴下过渡流畅，末帧与 Sleep 首帧姿态一致
- [ ] Sleep 的趴下姿态与 idle 站立有明显区别
- [ ] snooze 行为：LieDown(一次性)→Sleep(循环)，过渡自然
- [ ] Sleep 循环不含趴下过渡帧，纯呼吸循环

### 全局验收

- [ ] 宠物日常空闲时：idle 站立 → 偶尔 Walk 踱步 → 偶尔 Yawn → 回 idle（自然的生活感）
- [ ] snooze 触发时：idle → LieDown 趴下过渡 → Sleep 睡觉呼吸 → 被打断后切 idle
- [ ] 拖拽时：surprise(惊吓) → Dragged(悬空循环) → 松手 → Pout(嘟嘴) → 回 idle。三阶段不冲突
- [ ] 对话后：情绪反应（Happy/Cold 等）播 1~2 秒 → 回 idle → 日常行为继续
