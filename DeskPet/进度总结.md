## 一、当前已完成

### 1. 后端核心系统 (Rust) — 32/32 测试通过，无编译警告

| Rationality | `soul/rationality.rs` | 由尽责性推导回弹参数 |
| Curiosity | `soul/curiosity.rs` | Off/Normal/Enhanced 三级 + 方向权重推导 |

| EmotionalEvent | `soul/emotional_event.rs` | 12种事件枚举 + love_hate_delta/baseline_delta |
| Soul | `soul/soul.rs` | 聚合根: 事件应用 + tick + 双层连续人格描述生成 |
| Ghost | `ghost.rs` | 生成/传送(signature变更+微扰)/JSON序列化/文件读写 |
| Memory | `memory/*.rs` | STM/LTM/Experience/ContextWindow 三层体系 |

| GhostFile | `data/ghost_file.rs` | AES-256-GCM加密 + HKDF密钥派生 + 自动 master key 管理 |

### 2. 服务层 + 数据库

- **数据库**: SQLite 8张表 (Ghosts/ChatMessages/EmotionalEvents/ShortTermMemories/LongTermMemories/MasterImpressions/ConversationChunks/Experiences/AppState) + 完整CRUD
- **AI服务**: OpenAI 兼容协议统一接口 (chat/vision/image)，支持独立 vision_model 和 image_gen_endpoint
- **记忆服务**: 三层压缩框架 (本地即时→AI语义→经验提取) + 优先级加载
- **热键服务**: Ctrl+Alt+X 截图 + Ctrl+Alt+C 对话 (Pressed 状态检查)
- **截图服务**: Win32 API (GetDC/BitBlt/GetDIBits) + png crate，DPI感知，15秒超时
- **时间线服务**: 情感tick (60s) + 不活跃检测 (24h/72h) + 好奇心调度 (5min)
- **记忆压缩器**: STM→LTM 批量AI压缩 + 经验提取 + **AI辅助记忆模糊化 (P9)**
- **情感分析**: 对话后AI提取 event_type + love_hate_hint + 6维印象delta
- **注册的 Tauri 命令**: 28个

### 3. 前端

**桌宠渲染**: PetRenderer 三策略 (CSS🧪/ Spritesheet✅ / Spine🔒)
- Spritesheet: Canvas逐帧 + frameTags帧范围 + crossfade过渡 + 8种AnimationState
- 朝向系统 (isFlipped + scaleX(-1)) + 5种移动风格 (bouncy/slide/float/walk/teleport)

**漫画气泡对话**: BubbleDialogue + BubbleMessage 组件
- pet 气泡: 白底黑边+偏移硬阴影+三角尾巴 (日系漫画风)
- user 气泡: 淡绿底绿色边+右对齐
- system 气泡: 暖黄虚线+居中
- 打字指示器: 三点跳动 ●◉●
- 10秒自动淡出 (输入聚焦/chatLoading时不计时)
- 触发方式: 点击宠物 / 对话按钮 / Ctrl+Alt+C

**其他前端**:
- 可折叠面板 (frosted glass): 人格6维条形图 / 事件按钮 / 情感时间线 / 渲染器切换
- AI配置表单: Endpoint/API Key/Model/Vision Model/Image Model/Image Gen Endpoint
- TTS面板: 语音开关 + 语速滑块 + 音调滑块 ← P9
- 截图浮层: 全屏覆盖 + 鼠标框选区域 + ESC取消
- 窗口拖拽: CSS -webkit-app-region: drag
- 设置窗口: 独立 WebviewWindow + Tauri event 双向同步

### 4. 关键决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 情感模型 | 方向敏感阻尼 + 可变基线 | v1 弹簧模型导致长期关系回归平淡 |
| 防复制 | 叙事性软约束 + 微扰 | DRM 伤害用户体验 |
| 记忆压缩 | 三层渐进 (本地→AI→情感) | 降低 API 成本 |
| 技术栈 | Tauri 2 + Vue 3 + Rust | Web 栈天然适合自由形状 UI |
| AI 接入 | OpenAI 兼容协议统一 | 90%+ 模型兼容此协议 |
| 截图 | Win32 API + png crate | DPI 感知、无外部进程依赖 |
| 窗口 | 320×720 透明无边框置顶 | 桌宠浮在桌面上 |
| TLS | rustls (非 native-tls) | 显式指定避免 HTTPS 请求失败 |
| Ghost 加密 | AES-256-GCM + HKDF-SHA256 | 每文件独立 salt+nonce，前向安全 |
| 对话交互 | 热键+点击 → 气泡浮层 | 比面板内输入更符合"桌面伙伴"定位 |
| 气泡风格 | 日系漫画风 (硬描边 + 三角尾巴) | 设计文档要求的风格 |
| 动画映射 | AnimationState 8种 → 策略模式 | 零代码改动即可切换渲染器 |
| 时间线服务 | timeline_tick 替代 tick_ghost | 统一情感tick + 不活跃 + 好奇心 |
| TTS | SpeechSynthesis (离线) + Edge TTS 规划 (在线) | 最低可用已就绪，待优化语音质量 |
| 人格 Prompt | 双层连续阈值 | 6维人格每维标签层+细节层，消除5档离散跳变 |
| 生图触发 | `[GENERATE_IMAGE:描述]` Prompt 标记 | AI 自主决定何时画图 |
| 情感事件应用 | 对话 AI 主导 / 非AI 硬编码 | 消除 Sensibility 3次冲击、Impression 2次冲击 (P8) |
| 记忆模糊 | 数值调整 + AI 文本模糊双机制 | 设计文档 §4.3 完整实现 (P9) |
| 窗口拖拽 | CSS -webkit-app-region: drag | Tauri 2 无边框窗口标准做法 |

**已可用的完整功能**:

- AI 辅助记忆模糊 (传送时按代数递增模糊文本)
- 加密 Ghost 文件 (AES-256-GCM)
- **Lottie 骨骼动画渲染器** (3 种渲染模式: CSS/Spritesheet/Lottie P12)

### 已知限制

1. **截图**: 首次约 0.5 秒，15 秒超时保护；高 DPI 下个别情况需确认
2. **TLS**: 使用 rustls，部分企业代理环境可能需要 native-tls
3. **平台**: Windows 10/11 良好，Win7 不支持透明效果
4. **Spritesheet**: AI 生图占位，后期需手工重置为像素风
5. **Lottie 素材**: 渲染器框架就绪，需提供 8 种心境的 Lottie JSON 素材
6. **图像生成**: 需配置支持生图的 API，DeepSeek 不支持；已支持独立 endpoint
7. **Edge TTS**: 需联网，离线时自动降级到系统语音
