### 交互设计

```
常态: 桌面浮着宠物 🐱 + 名字 + 心情条 + 截图按钮 + 对话按钮
  ↓ 点击宠物 / 点击对话按钮 / Ctrl+Alt+C
弹出漫画气泡对话区（气泡+输入框）
  ↓ 用户输入 + Enter
输入框保留 → pet 漫画气泡弹出（带三角尾巴指向pet）
  ↓ 最后一条消息后10秒无操作（输入聚焦时不计时）
气泡自动淡出 → 回到常态
```

- **pet消息**: 白底+2.5px黑描边+偏移硬阴影+左下角三角尾巴 (日系漫画风)
- **user消息**: 淡绿底+绿色描边+右对齐+右下角尾巴
- **system消息**: 暖黄虚线边框+居中+小字
- **打字指示器**: 三点跳动动画 `●◉●`
- **自动消失**: 输入框失焦后10秒无操作淡出（打字中不消失）
- **chatLoading**: 发送消息时显示typing指示器，禁止重复发送

## 七、已知限制

1. **截图服务**: Win32 API 直接截屏，首次截图约0.5秒，15秒超时保护
2. **reqwest TLS**: 使用 rustls，部分企业代理环境可能需要改为 native-tls
3. **透明窗口**: Windows 10/11 支持良好，Windows 7 不支持 acrylic/blur 效果
4. **Spritesheet 素材**: 当前使用 AI 生图占位，后期需参考AI图手工重置为像素风
5. **消息持久化**: 对话消息目前仅保存在前端内存中，刷新后丢失
6. **气泡尾巴**: CSS 三角尾巴，pet 气泡带双层描边效果（外三角黑，内三角白模拟描边）
7. **好奇心动画面板**: 好奇心的 Enhanced 模式 UI 入口已有，但后台截屏分析功能未实现
8. **时间线状态**: TimelineState 当前存储在内存中，重启后丢失（不活跃计时重置）
9. **pet移动范围**: movePetToScreenshotRegion 使用 clamp 限制在窗口内偏移，无法真正移动窗口位置
