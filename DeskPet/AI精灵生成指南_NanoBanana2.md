## 一、生成规格总览

| 参数 | 值 |
|---|---|
| 单帧分辨率 | 64×64 px |
| 画布分辨率 | 512×512 px（8×8 像素格 × 8px/格）或 384×384 px（32×32 × 12px/格） |
| 背景 | 透明（PNG 32bit） |
| 色彩 | 限色（16~32 色可选，不超过 64 色） |

### Row 6 · speaking（说话）

**帧数：3–5帧 · 帧率：6fps · 循环：loop**

#### 文字版

```
像素画风格，64×64 像素，PNG 透明背景，16~32 色调色板，
边缘锐利，无抗锯齿，居中对齐，无描边，无水印。

猫娘说话/交谈动作，正面全身，像素画，逐帧绘制 4 帧：
帧1：嘴部张开呈说话状（○），眼睛注视前方，双臂自然下垂，
    身体直立，猫耳竖立，尾巴自然下垂略摆动；
帧2：嘴部张大（●），头部略微前倾，
    一只手抬起至胸前做手势，猫尾向上扬起；
帧3：嘴部闭合（-），头部回正，
    手放下，猫尾回到自然位置；
帧4：嘴部再次张开，重复帧2手势，
```

## 四、后处理流程

```
生成
  ↓
逐帧后处理（每帧单独处理）
  ├─ rembg U2Net 透明化背景
  ├─ Pixel Grid Detector 像素网格对齐
  └─ 裁切成 64×64 单帧 PNG
  ↓
拼合 Spritesheet
  ├─ Aseprite：新建 512×(64×N)px 画布，8列排列
  └─ 导出 PNG + JSON Hash
  ↓
导入项目
```

### Aseprite 拼合操作

1. 新建 512×(64×N)px 透明画布（N = 动画行数）
2. 导入所有动画帧（文件 → 导入帧）
3. 按 8 列排列（64÷8=8px/格）
4. 导出为 PNG + JSON Hash

### JSON 格式示例

```json
{
  "name": "catgirl_deskpet",
  "frameWidth": 64,
  "frameHeight": 64,
  "frames": [
    { "x": 0, "y": 0 },
    { "x": 64, "y": 0 },
    { "x": 128, "y": 0 },
    ...
  ],
  "animations": {
    "idle": { "row": 0, "frames": [0,1,2,3,4], "fps": 4, "loop": true },
    "happy": { "row": 1, "frames": [0,1,2,3], "fps": 6, "loop": true },
    ...
  }
}
```

## 五、生成效率建议

### 推荐批次策略

| 优先级 | 动画 | 建议生成方式 |
|---|---|---|
| P0 | idle / Walk / Dragged / Pout | **优先生成**，先验证角色一致性 |
| P1 | Yawn / Stretch / LieDown / Sleep | 次优先，衔接关系要严格对齐 |
| P2 | 其余动画 | 最后按需生成 |

### 单帧 vs 横条的选择

- **单帧生成**：适合所有帧，尤其细节丰富的表情帧（idle、surprise、pout）
- **横条生成**（一次出多帧）：适合动作差异小的帧组，如 Walk、Spin、Shiver
  - 横条提示词加一句：`"生成一张 X×64 像素的横向像素画：N 个猫娘[动作名]帧从左到右依次排列，每帧 64×64 像素，无间距，透明背景"`

### 参考图锚定使用说明

1. 选一张最有代表性的猫娘全身图作为参考（命名如 `ref_catgirl.png`）
2. 首次生成时上传参考图，后续同角色动画共用同一张参考图
3. 首帧验证一致性后再批量生成
